# OpenClaw fork — v1.6 extended animations (2026-11-11)

This fork integrates upstream v1.6.0 (4dd14d6) with the existing OpenClaw feature set and the exact independently validated production-v6 runtime. It supersedes the earlier, narrower OpenClaw contribution in upstream PR #443; this release is maintained in the fork, not a claim of upstream acceptance.

## Changes
- Adopt upstream v1.6 characters/wardrobe/pixel editor, roster, sidebar/mobile UI, explicit-play radio, reconnect and lifecycle fixes.
- Preserve metadata-only OpenClaw activity aggregation, friendly configured-agent names, working/tool/idle and native completion, separate child agents and child-only 120-second inactivity cleanup.
- Keep relay authentication separate from admin/usage/WebSocket/terminal/appearance permissions; no transcripts, prompts, replies or tool payloads are exported by the relay. Claude-specific usage/resume features remain capability-gated, not OpenClaw controls or Codex quota indicators.
- Preserve saved appearance assignments, hash-based external catalogs, Save/Cancel/Random, cleaner labels, work-only/always visibility preferences, nonoverlapping gear/close controls and 0.25-step zoom.
- Add exact 880x96 sheets: 55 frames per direction, including 48 standing casting phases for work/reading at 100 ms per phase (10 FPS).
- Add exact 896x96 sheets: 56 frames per direction, including 48 reading-only phases at 100 ms; final column is reserved and not played. Typing retains two frames at 300 ms.
- Preserve 112x96 legacy and 128x96 upstream sheets, walking, seated/standing alignment, mirroring, phase wrapping and tool-switch normalization. These extensions are fork formats, not standard Pixel Index compatibility. See EXTENDED-CHARACTER-FORMATS.md.
- Preserve npm/OpenClaw plugin/status-line packaging, protocol generation and cleanup contracts.

## Validation and production status
Independent exact-artifact QA: 458 webview tests and 1,073 server tests passed; 23 server tests skipped. Packaging, relay, protocol generation, types and lint checks passed (existing App.tsx hook warning remains). Independently rebuilt 188 distribution outputs were byte-identical. Browser tests observed all 48 casting and reading phases with synthetic sheets, plus child expiry, appearance persistence, mobile layout and terminal lifecycle.

The same sealed runtime was installed and accepted in production on November 11, 2026: all 188 installed files verified, real OpenClaw snapshot/tool/status feed and desktop/mobile reload checks passed. Existing settings/layout/external asset registrations were preserved.

Limitations: synthetic QA is not a fresh real-provider inference lifecycle proof; production acceptance did not separately observe every phase of private artwork. Dependencies were reused, not freshly installed. No VSIX is supplied or claimed tested for this release. No npm registry, VS Code Marketplace or Open VSX publication is requested by this GitHub release.
